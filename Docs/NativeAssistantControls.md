# 原生听写、应用快照和助手配置

ChatGPT.app 与 Codex 在当前安装中使用相同的应用标识 `com.openai.codex`，共用 Codex 配置。

- L2：通过辅助功能触发原生「听写」按钮，不再发送旧版快捷键。
- R2：模拟左右 Command 同时按下，触发用户确认的全局应用快照快捷键；不切换应用，以便截图当前台前应用。ChatGPT/Codex 需运行并启用该快捷键。
- 轮盘默认八格：Codex、网页浏览器、Cursor、Grok Bot、通用 macOS、Finder、终端、Slack。
- Cursor 和 Grok Bot 自动匹配各自应用；两者的 L2 使用 ControlDeck 通用听写，所有配置的 R2 均为全局应用快照。

升级首次启动会迁移未改动的 Claude/音乐默认轮盘槽，并按用户要求一次性将所有配置的 R2 统一迁移为应用快照。其他按键及自定义轮盘槽保持原样；迁移后仍可手动修改 R2。原有 Claude、音乐配置仍可在设置中选择。

原生听写只匹配目标应用当前窗口中唯一、启用且支持按下的按钮，按精确名称检查标题、说明和帮助文本。没有匹配、匹配不唯一、搜索超过复杂度限制时不执行操作；重复节点会去重，不可读分支不会阻止其他可读分支的搜索；不会退回到发送按钮、语音通话或猜测的快捷键。停止听写也要求仍处于启动时的窗口。

目前用户截图只确认了「听写」提示文字。「停止听写」及其他语言的候选文字尚未经过此版本应用的实际辅助功能树验证。代码和回归测试通过并不代表原生集成已经实测成功。若系统未暴露这些控件，或录音中按钮使用不同名称，状态栏会报告无法定位；需要真实控件名称补充适配。

## 安装后验证

1. 退出 ControlDeck，替换 Applications 中的应用，再启动。
2. 打开 ChatGPT/Codex 的输入框，确认 ControlDeck 当前配置为 Codex。
3. 先轻按 L2，检查原生听写是否开始；再次按下或测试长按松开时，检查是否正常停止并插入文字。
4. 保持要截图的应用在台前，使用绑定「Codex · 应用快照」的配置按 R2，检查是否捕获该应用。先松开实体键盘修饰键；若无动作，先确认手动同时按左右 Command 能否触发。所有配置的 R2 默认均为应用快照。
5. 打开轮盘，确认 Cursor 和 Grok Bot 两项；选中后松开 Options，会切换配置并请求激活或启动关联应用。通用 macOS 只换配置。未安装或激活失败会单独提示。

旧的已安装工具包不会自动覆盖：更新应用后重新使用安装工具按钮更新工具包，才能让其接受新增 `codexAppSnapshot` 动作。无需更改系统语言或清空已有配置。

## 系统 Games 干扰

应用在连接、回到前台及控制器自定义配置变更时重新请求禁用系统手柄手势。Apple 将此 API 定义为偏好，不能保证系统接受；后台输入监听也不提供独占访问。长按 L2 打开 Games 的硬件现象仍待复测，不能据此断定是 AeroSpace 或 L2 的系统默认动作。可在系统设置的 Game Controllers 中检查此控制器的自定义动作；本次未修改系统设置。
